Project Background

왜 TONOTE인가

향수 입문자들은 전문 용어, 매장 압박, 온라인 리뷰의 한계 사이에서 선택 마비를 경험한다. TONOTE는 그 진입 장벽을 감성 언어와 AI로 해소한다.

💡 핵심 가치 제안

"향수 언어를 몰라도,
나만의 향수를 찾을 수 있다"

감정을 말하면 AI가 시(詩)로 향수를 건네는 경험. 전문 용어 없이, 직원 눈치 없이, 내 페이스대로.

Visual Mockup

Motion Sequence

0.0s

배경 페이드인 + 황금 입자 상승

깊은 #0C0A08 배경 위에 황금빛 미스트 입자들이 아래에서 위로 천천히 부유. 향수 분자의 확산을 시각화.

0.2s

타원 윤곽선 드로잉

SVG stroke-dashoffset 애니메이션으로 황금 타원이 1.6초에 걸쳐 스스로 그려짐. 딥티크 오발 레이블에서 영감.

1.4s

🌿 아이콘 + 황금 글로우 등장

타원 중심에서 식물 아이콘이 부드럽게 페이드인. drop-shadow로 황금빛 발광 효과.

1.7s

TONOTE 로고 자간 수렴

letter-spacing이 넓은 값(0.5em)에서 좁아지며(0.28em) 로고가 "모이는" 느낌으로 등장.

2.3s

황금 수평선 확장

가늘고 투명한 선이 중심에서 양쪽으로 확장되며 로고 아래 섹션 분리.

2.6s

감성 카피 페이드인

이탤릭 세리프체로 2줄 카피가 부드럽게 등장. 3초가 지난 후 전체 화면 스케일 업 & 페이드아웃.

TONOTE 04 — Splash Copywriting

Emotional Copywriting

한 편의 시처럼
읽히는 카피

전문 용어 없이, 브랜드의 철학을 단 두 줄로 전달한다. 유저가 "기다리는" 감각 대신 "초대받는" 감각을 갖도록 설계한다.

✦ 최종 채택 카피

"당신의 기억 속에 잠든 향을,
오늘 다시 꺼내드립니다."

선택 이유: '기억'이라는 보편적 감각 언어로 향수 경험을 풀어냄. '잠든'이라는 시적 동사가 감성 브랜드의 톤을 결정짓는다.

▽ 후보 카피 (비교)

"말하지 않아도 알아요,
오늘 당신에게 필요한 향."

AI의 공감 능력을 강조. 다소 직접적으로 AI를 드러낸다는 단점.

"감정은 향이 되고,
향은 당신이 됩니다."

철학적·추상적. 입문자에겐 다소 거리감이 있을 수 있음.

TONOTE 07 — Interactions

Micro-interactions & Animation

보이지 않는 곳에서
감성이 살아 숨쉰다

인터랙션은 "기능을 완료했다"는 신호가 아닌, 브랜드의 감성 언어다. 모든 전환과 반응은 조용하고 우아하게 처리된다.

트리거 효과 유형 상세 설명 우선순위
스플래시 → 홈 전환 Scale + Fade 스플래시가 1.04× 스케일 업되며 0.9s 페이드아웃. 홈 화면은 아래서 translateY(24px) → 원위치로 등장. P0
AI 카드 탭 Slide Up AI 채팅 오버레이가 translateY(100%) → 0으로 0.5s cubic-bezier(.4,0,.2,1) 슬라이드 업. 배경 홈 화면은 그대로 유지. P0
AI 입력창 플레이스홀더 Fade Cycle 3.8초마다 opacity 0 → 0.4s 대기 → 텍스트 교체 → opacity 1. 이탤릭 세리프 5문장 순환. P0
AI 응답 생성 중 Dot Bounce 세 개의 원이 순차적으로 Y축 이동 + 황금색으로 변색. 0.9s infinite. 실제 생각하는 느낌 전달. P0
AI 카드 hover/active Gradient Border 카드 테두리 위에 황금-장미 그라디언트 레이어가 opacity 0 → 1로 전환. 클릭 시 scale(.99). P1
황금 입자 배경 Canvas Loop 90개 황금 입자가 아래→위 부유. 스플래시와 메인 화면 배경 앰비언트 오브(blur 90px) 모두 무한 드리프트. P1
하트 / 좋아요 Scale Pop 탭 시 1.3× 스케일 업 후 원위치. 🤍 → ❤️ 즉시 전환. 별도 로딩 없이 낙관적 업데이트. P2
무드 칩 선택 Color Shift 선택 시 background → gold, color → noir로 0.2s 전환. 비선택 칩은 동시에 해제. P2

✦ 인터랙션 설계 원칙

압박 없는 탐색

앱이 먼저 행동을 유도하지 않는다. 팝업, 강제 CTA 없음. 사용자가 원하는 속도로 탐색.

조용하고 우아한 반응

모든 트랜지션은 0.3~0.9s 이내. cubic-bezier(.4,0,.2,1)로 자연스러운 물리감.

감성 우선 피드백

기능 완료 신호보다 감성 강화. 하트 애니메이션, 황금 글로우 등이 그 예.
